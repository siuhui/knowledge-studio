# KnowledgeBase — PRD

## 定位

**个人的本地知识检索与分析工具**，把文档丢进去，能搜、能问、能深度分析。

一句话：把文档丢进去，能搜、能问、能深度分析。

---

## 用户画像

- 想快速检索项目文档、技术笔记、代码片段
- **没有**组织架构、没有审批流、没有权限分级

---

## 产品边界

### 做

- 创建多个 KnowledgeBase（知识库），每个有独立的数据源和文档集
- 接入多种数据源：本地文件上传、GitHub 仓库、Web URL、API 数据
- 文档自动索引：解析 → 切片 → 向量化 → 可检索
- 混合检索：关键词 + 向量，带来源引用
- AI 分析：不只是问答，能做摘要、对比、结构化提取
- 本地优先，S3 兼容存储；LLM 与 Embedding 走 API，其余数据本地化

### 不做（v0.x）

- 多用户 / RBAC / 权限分级 / SSO
- 团队协作 / 评论 / 审批流
- 审计日志 / 合规
- 企业级高可用 / K8s 部署
- 实时协同编辑

---

## v0.1.0 范围：最小可用

### 核心链路

```
注册/登录 → 创建 KnowledgeBase → 上传文件 → 索引 → 检索 → 带引用回答
```

### v0.1.0 交付物

| 能力 | 说明 |
|------|------|
| 身份认证 | register / login，JWT token（仅身份，无权限体系） |
| KnowledgeBase CRUD | 创建、列表、详情、更新、删除知识库 |
| 文件上传索引 | 上传 PDF / Markdown / 纯文本，自动解析索引 |
| 检索 API | 关键词 + 向量混合检索，返回 chunk + 引用 |
| 问答 API | RAG 问答，带 source 引用 |

### v0.1.0 硬指标

- 索引速度：100 页 PDF < 30s
- 检索延迟：P95 < 1s
- 检索命中率：人工抽样 >= 80% 满意
- 回答引用覆盖率：100%（每次回答必须带引用）

## 技术原则

- **模块化单体**，不拆微服务
- **PostgreSQL + pgvector**，向量检索 + 全文搜索
- **Python FastAPI**，纯 API + 可选 Web UI
- **LLM + Embedding 走 API**（唯一外部出口），文本数据本地存储
- **S3 Compatible Storage**（MinIO 开发 / 云 S3 生产），文件与配置可备份可迁移
- **本地开发靠 Docker Compose**，生产可按需替换为云服务
