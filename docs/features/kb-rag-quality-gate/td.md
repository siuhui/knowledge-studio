# v1.0 RAG 评测基线与发布门禁

## 1. 目标

建立 v1.0 的离线+线上质量基线，作为发布前必过门禁。

---

## 2. 评测数据集

- 数据规模：100~300 条高价值真实问题
- 分布要求：
  - 事实问答 40%
  - 流程问答 40%
  - 对比/解释 20%
- 每条样本包含：标准答案、可接受引用、不可接受回答示例

---

## 3. 指标定义

### 3.1 检索指标
- Recall@10
- MRR
- 首条命中率

### 3.2 生成指标
- 引用覆盖率（关键结论有引用）
- 幻觉率（无依据结论）
- 可执行性评分（1~5）

### 3.3 业务指标
- 首次响应时长（FRT）
- 用户满意度（Thumbs up）

---

## 4. v1.0 上线门槛（建议）

- Recall@10 >= 0.75
- MRR >= 0.60
- 引用覆盖率 >= 95%
- 幻觉率 <= 8%
- P95 首字延迟 < 3 秒

任一指标不达标：不得全量发布。

---

## 5. 评测流程

1. 每次检索策略/Prompt/模型变更触发离线评测
2. 与上个稳定版本对比差异
3. 通过后进入灰度（10% -> 30% -> 100%）
4. 灰度期间监控线上满意度与错误率
5. 不达标自动回滚

---

## 6. 结果归档

每次评测需归档：
- 评测版本号（code/index/prompt/strategy）
- 指标结果
- Top 失败样本及归因
- 修复任务清单
