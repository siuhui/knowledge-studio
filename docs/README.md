6. 迭代文档入口：[iterations/README.md](./iterations/README.md)
7. 发布映射入口：`docs/releases/<version>/README.md`

## 三层文档体系
- 长期层（事实源）：`docs/features/` 中的功能 PRD/TD
- 迭代层（执行态）：`docs/iterations/` 中的计划/RFC/复盘
- 发布层（映射态）：`docs/releases/` 中的版本范围与结果

## 版本语义
- `v0.x`：内部开发版本（不上线）
- `v1.0`：首个生产发布版本（GA）
- `v1.x`：生产迭代版本

## 目录说明
- `docs/product`：全局产品目标与路线
- `docs/architecture`：全局架构与跨功能技术约束
- `docs/engineering`：工程规范、流程、运行手册
- `docs/ai`：Prompt、Agent 策略与评测规范
- `docs/features`：功能级单一事实源
- `docs/iterations`：按版本迭代执行文档
- `docs/releases`：版本映射与发布记录
